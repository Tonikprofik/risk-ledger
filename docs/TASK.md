# Project scope

Risk Ledger reports property insurance loss experience from four CSV inputs: assets, policies, claims, and monthly exchange rates. A reviewer can look up a portfolio, compare its perils, and see which records were excluded and why.

The API provides a portfolio breakdown, ranked portfolio totals, and a data quality report. The bundled synthetic sample exercises missing premiums, mixed currencies, and excluded claims. The independent verification script recalculates the results from the input files.
